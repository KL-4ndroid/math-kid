# 魔法數學浮空島 · Magic Math Islands

為 4–6 歲幼兒設計的互動數學冒險遊戲，使用 React、Vite、Three.js、React Three Fiber 和 Drei。

## 本機啟動

建議使用 Node.js 20.19+ 或 22.12+。

```bash
git clone https://github.com/KL-4ndroid/math-kid.git
cd math-kid
npm ci
npm run dev
```

開啟終端顯示的本機網址。

## 正式建置

```bash
npm run build
npm run preview
```

靜態產物位於 `dist/`。本專案不需要 API 金鑰或後端服務。

## 遊戲內容

- 數數森林：數出 1–5 個動物或水果。
- 形狀城堡：配對三角形、正方形和圓形。
- 比大小牧場：找出點心比較多的一組。
- 加法麵包屋：用草莓練習總和不超過 5 的加法。
- 規律彩虹橋：完成顏色或形狀的重複規律。

答對即可收集星星；進度保存在目前瀏覽器的 localStorage。所有島嶼皆可自由進入，重返島嶼會產生新題目。

## 操作與無障礙

點擊 3D 島嶼或下方島嶼按鈕開始。拖曳旋轉地圖，滾輪或雙指縮放。遊戲中可按「聽題目」重新朗讀；支援鍵盤 Tab、Enter 和 Escape 返回地圖。

所有 3D 物件皆由基本幾何產生，沒有外部模型、圖片、字型或音訊素材。音效由 Web Audio API 合成，題目使用瀏覽器 SpeechSynthesis 的 `zh-TW` 語音。實際語音依裝置安裝的語音而定；若自動朗讀被瀏覽器限制，請點擊「聽題目」。3D 場景需要 WebGL；無法顯示時仍可用下方島嶼選單進入遊戲。

## 故事第一章：阿栗的麵包店

首頁點選「打開麵包店的故事」，可體驗五段相連故事：第一爐麵包、小兔子的早餐、小熊的野餐籃、花園下午茶、星光開店慶典。

每段包含兩個操作任務，使用「合併、拿走、補空位」理解 5 以內的加減法。可以點選點心再點目的地，也可以拖曳。操作完成後，將實物變化連結到數量與算式。提供逐步語音、操作示範與語音數數，不設計時或扣分。

完成故事可取得五件固定位置的店面裝飾，並選擇遮陽棚顏色；自由烘焙可反覆加入、送出 0–5 個點心。故事、當前步驟與裝飾會自動保存在本機。從任務返回麵包店也可先自由烘焙，之後再接續。故事可重玩，重玩不會重複發放禮物。

新模組位於 `src/bakery/`，不影響原有五座小島的單題遊戲。進度保存在 `magic-math-bakery-v1`，與原版星星紀錄分開。若瀏覽器禁用儲存，介面會提示無法永久保存。

```bash
npm test
```

測試涵蓋故事資料、數學範圍、進度續存、重玩、損壞的儲存資料。另以 Chromium 手機尺寸實測五段故事、十個任務、提示／重試、中途重新整理、店面保存、自由烘焙邊界與原版遊戲。中文語音的實際聲音品質仍依裝置語音支援而定。


### 不識字孩子的操作引導

首頁的狐狸大按鈕可直接進入故事。麵包店預設使用中文語音逐步提示，並以動態小手標示「點心 → 盤子 → 數量卡」，選取後指引才切換。數量卡附圓點，答錯時逐個亮起實物並數數；不直接標記正確答案。

「看我做」提供可重播的點選搬運動畫，示範不會代做任務或改變進度。點小狐狸可重聽下一步。停留時提供最多兩次溫和提醒，不催促、不扣分；靜音時仍保留圖像指引。故事開始、答對、收禮物皆有明確手勢與下一步語音。

語音需瀏覽器／裝置提供中文 SpeechSynthesis；首次點狐狸按鈕啟動互動。已用手機尺寸驗證動態指引、逐個數數、示範不改進度、提醒與靜音，以及五段故事回歸流程。實際發音及四歲孩子能否獨立理解，仍需在目標裝置與孩子試玩中觀察。

### 角色與互動動畫

阿栗現在由 CSS 幾何形狀組成，會眨眼、搖尾巴與打招呼；朗讀開始／結束時會同步嘴巴動作，取消舊語音不會讓角色繼續說話。完成任務會有短暫跳躍和星星慶祝。

搬運點心使用真實來源與目的地座標，沿小弧線移入盤子並輕輕落下。飛行中的新點心在盤子內暫時隱藏，避免畫面重複數量；搬運期間阻擋重複輸入，數量卡會在落下後出現。進度在操作時保存，因此動畫途中離開也能接續。

自由烘焙新增出爐與數量變化動畫，店面有緩慢飄雲、彩旗及裝飾出現效果。所有動畫均無外部圖片、影片或新增動畫套件；系統開啟「減少動態效果」時，角色與介面保持靜止，點心即時放入。

已以 Chromium 驗證飛行座標、重複輸入保護、落下顯示、語音事件同步、減少動態、中途離開與續玩，並回歸五段故事及十個任務。
